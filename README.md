# Shop Simulator

## Запуск на Windows

Установите Unreal Engine 5.8.4 и запустите `Open-Project.cmd` двойным щелчком.
Скрипт найдёт движок, зарегистрирует его для текущего пользователя и откроет
проект напрямую. Права администратора не нужны.

Если движок не обнаружен автоматически, укажите папку установки:

```powershell
.\Open-Project.ps1 -EngineRoot 'D:\Epic Games\UE_5.8'
```

Для регистрации движка и настройки Git hooks и Git LFS без запуска редактора:

```powershell
.\setup.ps1
```

В `setup.ps1` также можно передать `-EngineRoot`.
Проверка обнаружения без изменения реестра и запуска редактора:

```powershell
.\Open-Project.ps1 -CheckOnly
```

Регистрация хранится отдельно на каждом компьютере. После клонирования
запустите один из указанных скриптов. Сам файл `.uproject` не может исправить
реестр Windows; общая привязка проекта к версии `5.8` сохранена.
